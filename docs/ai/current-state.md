## Security posture (implemented)
Argon2id passwords; opaque sessions (`ms_admin_session`, HttpOnly, SameSite=Strict, Path=/api/v1/admin, 30 min idle/12 h absolute); CSRF Origin guard; login/reset throttling (fail-safe 503); default-deny permissions guard; audit log; AES-256-GCM field encryption (`FIELD_ENCRYPTION_KEY`) for TOTP secrets and private enquiry emails; helmet strict CSP on the API; 64 KB body cap; env validation refuses insecure production values. Privileged admin mutations are metered (20/min, 200/h per administrator; per-process fallback during a Redis outage; `429` + `Retry-After`). Production refuses to start without verified MySQL TLS (`?sslmode=verify-ca|verify-identity`) or with `DATABASE_ALLOW_PUBLIC_KEY_RETRIEVAL=true`. Not yet: Turnstile/public form limits (16), retention jobs, web-tier TLS/CSP/headers (23–24).
